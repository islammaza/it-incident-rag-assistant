# HTTP 500 Internal Server Error

HTTP status `500 Internal Server Error` means the server encountered an unexpected condition that prevented it from fulfilling the request. It describes the response class, not the root cause. The application log, web server log, request timestamp, route, and a sanitized reproduction are needed to identify the failure.

## Troubleshooting approach

- Confirm whether all routes fail or only one operation.
- Correlate the request time with application and reverse-proxy logs.
- Check recent deployments, configuration changes, and dependency health.
- Look for uncaught exceptions, invalid input handling, missing files, database errors, or permission failures.
- Reproduce with a minimal non-sensitive request.
- Verify the response after correcting the underlying application problem.

A proxy can return a 500 generated by the upstream application or by its own processing, so inspect both layers. Avoid replacing the response with a generic retry without collecting the server-side error. The client generally cannot fix a genuine 500 response by changing browser settings.
